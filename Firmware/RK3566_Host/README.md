# RK3566 Host Firmware / Software

Host-side code for the `RK3566` SoC (U1). Talks to the STM32G0 NFC MCU (see `Firmware/STM32G0_NFC_MCU`) over the link wired between the two sheets.

Not yet started. Planned scope:
- Driver/transport for the STM32G0 link
- Higher-level transit-card session handling and UI/storage
